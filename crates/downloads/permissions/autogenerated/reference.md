## Default Permission

Todos los comandos del descargador (yt-dlp).

#### This default permission set includes the following:

- `allow-fetch-info`
- `allow-scrape-page`
- `allow-probe-media`
- `allow-probe-sizes`
- `allow-start-download`
- `allow-cancel-download`
- `allow-default-download-dir`
- `allow-tool-versions`
- `allow-update-ytdlp`
- `allow-reveal-file`
- `allow-open-file`
